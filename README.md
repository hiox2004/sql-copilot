# SQL Copilot

Schema-grounded Text-to-SQL copilot (PostgreSQL first): plain-English question in, safe SQL and its result out. Built as a learning project, with a small fine-tuned model, retrieval over the schema and a business dictionary, and a self-correcting verification loop.

- **Set it up:** [docs/setup.md](docs/setup.md)
- **Learn the concepts:** open [docs/study-guide.html](docs/study-guide.html) in a browser
- **Project conventions:** [CLAUDE.md](CLAUDE.md)

Status: database (36 tables, seeded, consistency-checked) is done; the Python package, dictionary, retrieval, model and app are still to come. License: MIT.
